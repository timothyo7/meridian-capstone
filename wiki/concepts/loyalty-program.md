# Loyalty program

Meridian's customer loyalty program, per the [client brief](../sources/client-brief.md).

**Data handling note:** loyalty data is Restricted. It never enters this wiki
or any AI tool, and anything derived from it is Restricted regardless of
aggregation. Analysis of it happens in code against data outside this
repository. See the [data handling checklist spec](../../docs/superpowers/specs/2026-09-20-data-handling-checklist-design.md).
